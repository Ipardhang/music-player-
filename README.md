# Music Player

Browser-based music player with local uploads, persistent library storage, online search, artwork, playlist controls, and optional Spotify integration.

## Features
- Local audio file playback
- IndexedDB persistence for uploaded tracks
- iTunes Search API preview search
- Optional Spotify PKCE login and Web Playback
- Playlist, seek, volume, repeat, and autoplay controls
- Responsive glass-style interface

## Run
Serve the repository from a local HTTP server and open `project3.html` or `main`.
